Set up once

BG1 runs inside Disney's own pages. A small script loads it there for you. Pick your device:

  1. Get the Userscripts app. Install Userscripts from the App Store and open it once.
  2. Turn it on for Safari. In Settings, go to Apps → Safari → Extensions → Userscripts. Switch on Allow Extension, and set Other Websites to Allow.
  3. Install the BG1 script. Close Safari and open it again, then tap the button below. On the page that opens, tap the puzzle piece in the address bar, choose Userscripts, tap “Tap to install”, and then Install.
  4. Come back here. The badge at the top turns to Ready. Open a park and sign in.

  1. Use Firefox. Install Firefox and open this page in it.
